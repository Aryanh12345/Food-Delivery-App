# 🍔 Food Delivery App

A modern and responsive **Food Delivery App** built using **HTML, CSS, and JavaScript**.

This project demonstrates a food delivery website interface where users can explore food items, browse different sections, and interact with the application through a simple and intuitive design.

## 🌐 Live Demo

👉 **[Visit Food Delivery App](https://aryanh12345.github.io/Food-Delivery-App/)**

## 🚀 Features

- 🍔 Food item display
- 🍕 Food categories
- 🔍 Easy navigation
- 🛒 Food ordering interface
- 📱 Responsive design
- 🎨 Modern and attractive UI
- 🖱️ Interactive elements
- ⚡ Lightweight and fast
- 💻 Built using HTML, CSS, and JavaScript

## 🛠️ Technologies Used

- **HTML5** – Website structure
- **CSS3** – Styling and responsive layout
- **JavaScript** – Interactive functionality
